# Anti-cheat policy

Evection Hook is for single-player mods, co-op fun with friends who also want mods, quality-of-life tweaks and game research.

**We will not:**
- install into games that ship anti-cheat (Easy Anti-Cheat, BattlEye, GameGuard, XIGNCODE3, ACE, …) — the installer refuses;
- add anti-cheat bypasses, detection evasion, or ways to hide the loader;
- accept cheats designed to affect other players in public matchmaking.

**Why:** modding anti-cheat-protected games gets players banned, and bypass code gets projects taken down. Keeping this line lets
Evection Hook stay free, public, and safe to recommend.

If a game is flagged incorrectly (e.g. anti-cheat files are present but only used by a separate multiplayer executable), open a
**Game support** issue with the evidence.
